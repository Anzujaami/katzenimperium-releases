# Katzenimperium

Настольная игра в мире Katzenimperium
Первый доступный эпизод — детективная point-and-click новелла «Лишняя минута»

## Скачать игру

**[Открыть страницу загрузок](https://github.com/Anzujaami/katzenimperium-releases/releases)**

| Система | Скачать preview 3 | Требования |
|---|---|---|
| Windows x64 | [Katzenimperium-Windows-x64.zip](https://github.com/Anzujaami/katzenimperium-releases/releases/download/v0.1.0-native-preview.3/Katzenimperium-Windows-x64.zip) | Direct3D 12 или Vulkan |
| Linux x64 | [Katzenimperium-Linux-x64.zip](https://github.com/Anzujaami/katzenimperium-releases/releases/download/v0.1.0-native-preview.3/Katzenimperium-Linux-x64.zip) | glibc 2.39+ (например, Ubuntu 24.04), Vulkan |

Для скачивания не нужны аккаунт GitHub или приглашение
Это ранняя версия для знакомства с игрой и обратной связи

1. Скачай ZIP для своей системы и распакуй его целиком
2. На Windows запусти `Katzenimperium.exe`, на Linux — `Katzenimperium`
3. При обновлении закрой игру и сохрани свою папку `saves`; в архиве личных сохранений нет

Браузер, Godot, Python и компилятор игроку не нужны
В разделе Assets выбирай готовый пакет для своей системы; автоматически добавленные GitHub архивы «Source code» содержат только эту страницу, а не игру
Контрольная сумма каждого пакета находится в соседнем файле `.sha256`

## Управление

- Esc — пауза / назад, F11 — полный экран
- J — дело, M — карта, I — сумка
- Удержание H — места осмотра
- F5 — быстрое сохранение, F9 — загрузка с подтверждением
- Масштаб интерфейса, размер текста и прозрачность диалогового окна доступны в настройках
